# Seedance 提示詞收藏庫

把豆包 Seedance 靈感頁看到的好提示詞存下來,不怕頁面刷新後找不到。
每一條 = **截圖 + 提示詞全文 + 標籤**,做成可搜尋、可篩選、一鍵複製的圖庫網頁。

---

## 網頁怎麼看

- 檔案:`seedance/index.html`
- 開啟方式:
  - **手機/電腦瀏覽器**:如果這個 repo 有開 GitHub Pages,網址是
    `https://<你的帳號>.github.io/syi-art/seedance/`
  - 或直接用瀏覽器打開 `index.html` 檔案也可以
- 功能:上方搜尋框可搜提示詞/標籤/備註;點標籤可篩選(可複選,取交集);
  點任一張卡片會跳出大圖 + 完整提示詞 + 「複製提示詞」按鈕。

---

## 怎麼新增一條提示詞

### 你要做的(很簡單)
1. 在 Seedance 看到喜歡的影片,**複製提示詞文字**、**截一張圖**。
2. 把「提示詞文字 + 截圖」交給 Claude(貼上文字、附上圖片)。

### Claude 幫你做的
- 把截圖存進 `seedance/images/`
- **從提示詞自動抓關鍵字當標籤**(你不用自己想分類)
- 在 `seedance/data.js` 最上面新增一條紀錄
- commit + push,網頁就更新了

> 也就是說:你只負責「複製 + 截圖 + 丟給我」,整理入庫我來。

### 手動新增(如果你想自己加)
打開 `seedance/data.js`,複製最上面一整段 `{ ... }`,貼在陣列最前面,改內容:

```js
{
  id: "2026-08-13-01",          // 日期+序號,不要重複
  date: "2026-08-13",
  image: "images/你的截圖.jpg",  // 圖放進 images/ 資料夾,這裡寫檔名
  prompt: "提示詞全文…",
  tags: ["空靈", "雨景", "人物"], // 可放很多個
  note: "這條好在哪、想改哪裡",   // 可留空 ""
  source: ""                     // 參考影片連結,可留空
},
```

## Apple 捷徑(iPhone 快速收藏)— 方法 A:存到 iCloud 資料夾

這個做法最簡單、不用設定金鑰。捷徑把「截圖 + 提示詞」存到 iCloud Drive 的一個
資料夾,之後你把整個資料夾內容丟給 Claude,一次收進庫裡。

**捷徑步驟(在「捷徑」App 裡新增一個捷徑):**

1. **接收輸入**:動作類型設為「螢幕截圖」與「文字」(從共享表單接收)。
2. **取得剪貼簿**(Get Clipboard)→ 這是你剛複製的提示詞。
3. **要求輸入 / 選擇標籤**(可選):用「從清單選擇」列出你常用標籤,方便當下先標。
   > 不想標也沒關係,標籤 Claude 會幫你補。
4. **文字**動作:把提示詞 + 標籤 + 日期組成一段,例如:
   ```
   日期: [目前日期]
   標籤: [剛選的標籤]
   提示詞: [剪貼簿內容]
   ```
5. **儲存檔案**(Save File)→ 存到 iCloud Drive 的 `Seedance收藏/` 資料夾,
   檔名用日期時間(避免重複)。
6. **儲存截圖**:再加一個「儲存檔案」,把截圖存到同一個資料夾,檔名對應同一個時間戳。

**用法:** 在 Seedance 複製提示詞 → 截圖 → 從截圖的分享選單跑這個捷徑 → 完成。
累積幾條後,把 `Seedance收藏/` 資料夾的內容丟給 Claude,我幫你整批入庫、補標籤。

> 想升級成「按一下直接進 repo、免整理」的全自動版(方法 B,用 GitHub API),
> 跟 Claude 說一聲,我再把進階捷徑步驟給你。

## 這個庫的第二個用途:教 Claude 你的風格

累積十幾條之後,這些提示詞就是「教材」。Claude 可以拆解你收藏的寫法,
整理出**你自己的提示詞公式**。之後你只要用白話說想要的畫面(例如
「一個女生在雨中走路、很空靈」),Claude 就照你的風格產出一條 Seedance 能用的完整提示詞。
